## 🚀 Descripción

El proyecto es una web **spa (single-page application)** construida desde cero, con un diseño moderno que combina estética "tech" (estilo terminal) con una interfaz limpia y animada. El objetivo es presentar mi perfil profesional de una manera interactiva y atractiva.

## ✨ Características

-   **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y escritorio.
-   **Hero Section Dinámico:** Simulación de una terminal de comandos con efecto de escritura (typing effect) y animación de parpadeo.
-   **Navegación Fluida:** Menú de navegación que permite desplazarse suavemente entre las secciones.
-   **Slider de Tecnologías:** Carrusel infinito (infinite loop) mostrando las herramientas y lenguajes que domino (Python, HTML, CSS, JS, Flask, Git, etc.).
-   **Sección de Proyectos:** Tarjetas interactivas con efectos hover y enlaces a código/demos.

## 🛠️ Tecnologías Utilizadas

-   **HTML5:** Estructura semántica.
-   **CSS3:**
    -   Diseño Flexbox y Grid.
    -   Animaciones `keyframes` (typing, scroll infinito, flotar).
    -   Variables CSS para gestión de temas.
    -   Media Queries para diseño responsivo.
-   **JavaScript (Vanilla):** Lógica para interactividad y efectos.
-   **Font Awesome:** Iconografía.
-   **Google Fonts:** Tipografías 'Sixtyfour' (títulos estilo retro) y 'Roboto' (textos legibles).

## 📂 Estructura del Proyecto

```text
/
├── assets/           # Imágenes y recursos multimedia (logos, perfil, etc.)
├── index.html        # Estructura principal de la página
├── style.css         # Estilos y animaciones
└── script.js         # Lógica y scripts del lado del cliente
```
